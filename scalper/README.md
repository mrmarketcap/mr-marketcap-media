# Scalper — بات اسکالپ خودکار (OKX فیوچرز، BNB/USDT، لوریج ۳، Long+Short)

## استراتژی
- Long: کراس صعودی EMA9/EMA21، قیمت بالای EMA100، RSI بین ۵۰ تا ۷۲
- Short: قرینه‌ی بالا (کراس نزولی، زیر EMA100، RSI بین ۲۸ تا ۵۰)
- فیلتر: اگر نوسان (ATR) کمتر از ~۰.۰۸٪ قیمت باشد معامله نمی‌کند (کارمزد سود را می‌خورد)
- خروج: حد ضرر = ۱×ATR (به‌صورت سفارش trigger روی خود OKX هم ثبت می‌شود، پس با قطع شدن بات هم فعال است)، حد سود = ۱.۶×ATR (بات مدیریت می‌کند)
- Isolated margin، لوریج ۳ (سقف ایمنی ۵)؛ حجم محدود به بودجه×لوریج. اگر سفارش stop ثبت نشود پوزیشن بلافاصله بسته می‌شود.
- مدیریت ریسک: حجم معامله طوری که ضرر هر معامله ≤ ۰.۵٪ بودجه؛ توقف با ضرر روزانه ۲٪؛ سقف تعداد معامله؛ کول‌دان

## راه‌اندازی
```bash
cd scalper && pip install -r requirements.txt
cp .env.example .env     # کلید OKX + passphrase را بگذارید
python backtest.py --days 14          # ۱) اول بک‌تست
python bot.py                          # ۲) paper (قیمت واقعی، بدون پول واقعی)
python bot.py --i-understand-the-risk  # ۳) فقط با MODE=live در .env
```
## مسیر امن
1. بک‌تست روی چند ماه/چند جفت‌ارز (با کارمزد واقعی). اگر بعد از کارمزد منفی بود، لایو نکنید.
2. حداقل ۱–۲ هفته paper.
3. OKX Demo Trading: در حساب OKX حالت Demo را بزنید، API key مخصوص Demo بسازید، `SANDBOX=1 MODE=live` (سفارش واقعی روی پول مجازی). **این مرحله تست نشده؛ اولین بار با دقت لاگ‌ها را بخوانید.**
3b. لایو با `SANDBOX=0` و سرمایه‌ی کم (`QUOTE_BUDGET`). پوزیشن باز قبلی روی همین جفت‌ارز باید بسته باشد.
4. کلید API: فقط دسترسی Trade و Read؛ **Withdraw خاموش**؛ IP whitelist فعال.

## هشدار
با لوریج ۳ ضررها هم سه برابر می‌شوند (البته ریسک هر معامله با اندازه‌ی پوزیشن ۰.۵٪ بودجه محدود شده است). اسکالپ حساس به کارمزد و اسلیپیج است و سود تضمینی ندارد؛ بیشتر بات‌های اسکالپ خرد بعد از کارمزد ضرر می‌دهند. این کد ابزار آزمایش است، نه توصیه‌ی مالی.
